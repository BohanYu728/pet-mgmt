# 宠物管家系统整体视觉升级方案

状态：用户已确认清爽宠物生活风，按此方案执行。范围覆盖现有 Vue 用户端、登录注册、商户端和管理员端。

## 推荐方向

采用清爽的宠物生活品牌风格：云白背景、深蓝灰文字、暖橙主操作、少量青绿色状态。通过真实宠物摄影和照护信息布局建立特点，统一图标，替换杂乱字符图标与大面积表情占位。

色彩：背景 #F4F7FB、面板 #FFFFFF、正文 #253247、主操作 #E87832、辅助色 #2A7E86、浅色分区 #EAF3F8。中文采用系统苹方/微软雅黑字体，标题以字重与留白区分；数字使用清晰等宽数字。

备选方向：青绿医疗照护风，更克制但与现状接近；柔和多彩风，更活泼但管理表格的整体感较弱。推荐第一种。

## 各页面改造

- 全局：重新设计品牌标志、紧凑分组侧栏、顶部用户区；统一按钮、表单、状态、弹窗、表格和键盘焦点。
- 登录注册：宠物实拍与表单双栏，移动端保留精简照片区和完整表单。
- 首页：真实宠物照片主视觉、今日照护概览、档案卡片和待办提醒，减少重复的大按钮及空白。
- 宠物档案、照护、日志和相册：突出已有头像及照片，统一内容卡片、标签和操作层级；无头像时清楚呈现默认示意，避免把素材图误认为用户上传照片。
- 商城：突出商品照片、分类筛选、价格和库存，统一购物车与订单。优先使用商品自身图片；演示素材标注示意，不冒充商品实际包装。
- 医院、智能助手及其他 AI 页面：统一标题、表单、结果区和来源展示，保持地图及原有功能可用。
- 管理员及商户：清晰的统计、表格、筛选和操作按钮，照片只用于适合的商品或头像区域。

## 图片策略

优先检查并使用现有本地宠物图片；新增摄影素材选择可使用的来源并记录来源。素材存放为前端静态资源，避免运行时依赖随机图接口。保留用户原图，加入加载失败兜底、替代文本和适当的图片裁切展示。

## 验收

覆盖全部现有路由，桌面与手机无横向溢出；图片没有破图，弹窗及菜单可操作，文字与背景具有清晰对比。执行前端测试及生产构建，使用隔离演示环境核对三种角色页面，复验用户和宠物增删改、购物车及下单取消。保存新的 UI 截图。

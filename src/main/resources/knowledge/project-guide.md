# 宠物管家系统项目资料

## 账户与宠物档案
用户可注册和登录，登录后管理自己的宠物资料。宠物档案记录基本信息；健康记录和体重记录与宠物关联。此处描述系统功能，不构成兽医建议。

## 健康记录与提醒
系统可维护宠物的疫苗、驱虫、体检等健康记录，并提供提醒功能，帮助用户追踪后续事项。用户仍需依据兽医给出的具体接种和复诊时间安排。

## 日常日志
系统提供宠物日常日志记录，用于保存喂养、活动等日常情况。日志可辅助用户回顾变化，但不用于自动诊断疾病。

## 在线商城
商城提供商品分类浏览、商品详情、购物车和订单管理。商户可管理自己的商品，用户可查看购物车并创建订单。

## 智能辅助
原项目设计包含品种识别、情绪分析、健康报告、商品推荐和症状咨询等功能。识别及分析结果仅作辅助参考，不能替代兽医的检查和诊断。

## 资料来源与范围
本知识文件依据同项目《宠物管家系统设计与实现》中的摘要、研究内容与方法和功能模块说明整理，仅描述项目功能。它不含实时商品库存、个人宠物数据、医疗诊断结论或外部权威兽医指南。

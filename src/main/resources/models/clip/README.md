# 本地猫狗状态候选分析

模型：https://huggingface.co/Xenova/clip-vit-base-patch32
原始模型与许可证：https://github.com/openai/CLIP （MIT，附 LICENSE）
使用量化 ONNX vision/text 两个编码器，约 154 MB；在 Java ONNX Runtime 中运行，部署后不联网。

先用 CLIP 比较猫、狗、人物、景物、物体和鸟的主体描述；未确认猫狗时不分析。图像采用 RGB、整图等比缩放至 224、黑色补边和 CLIP 均值标准差。这里使用整图保留人物同框图片里的宠物，区别于官方默认的中心裁剪，可能影响模型表现。固定英文状态提示由同源 vocab/merges 分词；只包含 ASCII 字母和空格。每类使用三个状态描述的平均单位文本向量，与图片单位向量计算余弦相似度，列出六类候选。

结果是开放词汇图文相似度推测，未经宠物情绪数据集训练、校准和独立准确率验证。相似度不是概率，背景和人物可能造成误判。最高相似度小于 0.2 或前两项差值小于 0.01 时返回 uncertain；这些是工程拒判阈值，不是已验证可靠性的阈值。界面始终保留候选、模式、限制说明，不伪造置信度。

模型缺失或推理失败返回错误，不回退到颜色规则。损坏图片返回 HTTP 400。
